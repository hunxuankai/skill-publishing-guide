# 1.2.0 网页导入路线与实际表单核验

日期：2026-11-08。

本版新增 SkillHub.club 的正式网页导入路线。登录后的 `/app/skills` 提供名称、描述、分类、标签及文件导入控件；页面列出 ZIP、Markdown、文本，选择器另接受 `.markdown` 且允许多选。上传会自动创建技能和首版，因此表单核验保持只读。没有据此确认网页默认可见性、归档根层级、多 skill 解析、文件大小/数量、详情页二进制资源或最终公开动作。

Agensi 正式发布页已用浏览器实际读取，包括 ZIP、名称/摘要、描述、demo、兼容性、价格选项、权限、媒体及展开的可选区域。Name/Summary 的 maxlength 为 60/300；必填按界面星号记录，不能由 HTML required 缺失推出可省略。展开区域已恢复原状态，没有填写字段、上传、修改价格或提交审核。既有打包、审核、条款和代理路线仍按 2026-11-07 的官方文档证据使用。

SkillsDir.dev 当前显示部署暂时暂停，正常 TLS HTTP 为 402；原先所链接的投稿/CLI 仓库和 npm 包仍公开返回 404。暂停前字段保留历史日期，未被写成当前重新核验的规则；没有将站点暂停描述为投稿被拒绝或创建替代投稿入口。

README 继续列出 9 个渠道，区分实际表单、文档、本地 CLI 和真实发布的证据。SkillHub.club CLI 0.1.9 的本地检查沿用前版记录，没有重新冒充为本轮认证上传测试。

本次范围仍为表单与发布方法核验、本地版本及安装更新。原始界面记录已排除个人账号，HTTP 响应与受控评估放在本机 `.artifacts/live-publishing-forms-20261108-58d6d6403037/`；不进入运行包。详细结果见 [验证记录](../validation.md)。
