# Skill 发布指南

版本 1.2.3。帮助代理为一个 Agent Skill 准备发布包和页面介绍，按目标平台执行发布、更新与结果核验。

## 适用场景

- 发布或更新 GitHub、skills.sh、腾讯 SkillHub（skillhub.cn）、SkillHub（skillhub.club）、Skillstore、ClawHub、Agensi，以及符合贡献门槛的 VoltAgent 社区目录。
- 核对多技能仓库的单技能目录、GitHub repo/tree/raw URL 和 ZIP 根层级，保留实际运行依赖。
- 处理上传已接收但仍待审核、公开页仍旧、版本重复、请求超时或介绍内容没有同步的情况。
- 为需要手动提交的用户准备完整简介、概述和已核实的操作步骤。

## 本版与近期变化

1.2.3 补齐作者选择的 MIT 许可和包内版权声明；指南功能沿用 1.2.2。1.2.2 将发布包、触发描述、GitHub README、平台简介、详情概述及翻译/展示副本分别准备、提交和验收，并核对腾讯 SkillHub 的默认 SKILL.md、自定义概述和最终审核提交入口。当前覆盖 8 个渠道，已移除缺少可用投稿入口的 SkillsDir 路线。

## 使用方式

把包含 SKILL.md 的 `skill-publishing-guide` 目录安装到支持 Agent Skills 的宿主，然后请求：

> 使用 skill-publishing-guide，发布这个 skill 到指定平台，沿用现有语言、许可证和账号，分别核对新版包、简介和概述。

代理先读取入口，再按所选渠道加载参考页，复用已有工具和登录会话；缺少会影响下一步的信息时再请求用户处理。运行包只包含 Markdown/YAML，没有自动批量上传脚本，也不携带个人账号或平台凭据。

## 系统支持与依赖

指南可由支持 Agent Skills 的 Windows、macOS、Linux 宿主读取。真正发布时需要目标平台允许的浏览器、官方 CLI 或 API，以及相应网络、账号和发布授权。仓库维护工具使用 Python 3.10+、PyYAML、markdown-it-py/mdurl 和 PowerShell 7；这些维护库不属于使用指南的运行依赖。

## 验证范围与限制

维护验证在 Windows、Python 3.11.13 和 PowerShell 7 上执行，检查包结构、元数据、相对引用、文件哈希和隔离安装流程。此前独立使用评估涵盖单技能打包、模拟审核回执、超时和许可边界，以及完整介绍材料。SkillHub.club CLI 0.1.9 的本地启动、认证守卫和文件扫描经过隔离验证。

这些检查不代表 macOS/Linux 实机验证，也不证明所有市场已完成真实上传或审核。平台当前入口和条款以一手文档、实际界面及每次发布回执为准；接收、待审、公开版本、下载内容、简介和概述分别核验，不承诺固定审核或缓存刷新时限。VoltAgent 要求已有真实社区使用；不能为新项目编造采用情况。
