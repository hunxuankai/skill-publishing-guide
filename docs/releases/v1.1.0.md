# 1.1.0 本地更新

日期：2026-11-07。

新增 SkillHub（skillhub.club）的官方 CLI 发布路线，包括独立 staging、init/push/publish、文件过滤、已发布条目的更新行为、平台修订与作者版本及公开内容核验。该平台与腾讯 skillhub.cn 分别路由；README 逐项列出 9 个渠道、提交方式和限制。

补充 SkillsDir.dev 与 Agensi 的确认方法，并复查正式入口。前者所链接的投稿仓库、CLI 仓库及 npm 包仍返回 404；后者正常 TLS 校验仍因证书过期失败。保持受限状态，没有将主页可访问、历史表单或成功回执写成已上线。

本次核对官方文档及 npm 0.1.9 的发布包代码，校验了下载包的 SHA-512 integrity。原始 HTTP 状态、响应、哈希和耗时保存在本机 `.artifacts/`。网页实操检查因本机浏览器工具错误而跳过，没有执行登录、真实上传或发布。

本版本仅修改本地指南、验证及安装副本；不建立远程仓库，不向市场提交，不修改作者许可证，也不覆盖 v1.0.0 标签或旧版包。维护检查和独立使用评估见 [验证记录](../validation.md)。
